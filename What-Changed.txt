WHAT CHANGED IN 1.0.9

Includes the private 1.0.8 cross-tab protection: pause saving when stored
progress changes elsewhere, no automatic answer/result merging, reload and
single-tab instructions, supported saved-state migration.

Independent QA found one stale UI path: compare-before-write paused saving
but left the home checkbox/hint claiming it was on. A shared pause function
now updates the state, warning, checkbox and hint immediately from both
storage-event and comparison paths. Added assertions before render/reload
and warning persistence across routes. Both paths pass current checks.

Existing scenario/report/assessment/state/accessibility tests pass locally.
This remains defensive, not an atomic multi-tab transaction or browser-wide
guarantee. Guide unchanged, five pages. No human/conformance/learning or
legal/accreditation claims added. 1.0.8 was held for this fix, not released
by this task. No live changes.
